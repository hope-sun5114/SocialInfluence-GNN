# Project README
# 基于图神经网络的社交网络虚假信息传播建模与分析

## 项目简介

本项目面向社交网络中的虚假信息传播问题，基于图神经网络（Graph Neural Networks, GNN）
对信息传播过程进行建模与分析。通过融合用户语义特征、行为特征以及传播结构特征，
构建传播图并进行多分类预测，从而刻画不同类型信息在社交网络中的传播模式，
并进一步探索潜在的意见领袖节点。

本项目为课程《社会计算》相关研究与实验代码实现。

---

## 方法概述

### 1. 用户画像构建

针对社交网络用户，构建多维用户画像特征，主要包括：

- **语义特征（SBERT）**  
  利用预训练的 Sentence-BERT 模型对用户发布内容进行编码，
  捕获文本层面的语义信息。

- **行为特征（Behavior Features）**  
  包括用户转发、回复等行为统计特征，用于反映用户活跃度与行为模式。

- **结构特征（Structural Features）**  
  基于传播图结构提取的节点结构嵌入，用于刻画用户在传播网络中的位置关系。

上述特征在节点层面进行拼接，作为图神经网络的输入特征。

---

### 2. 传播图建模

以 Twitter15 数据集为基础，将信息传播过程建模为有向图：

- 节点表示用户或转发事件
- 边表示信息传播关系（如转发路径）
- 使用 `edge_index` 表示图结构（基于 PyTorch Geometric）

该传播图作为后续图神经网络模型的输入。

---

### 3. 模型设计

本项目实现并对比了多种模型：

- **Logistic Regression（LR）**  
  仅基于节点特征的线性分类模型，作为基础对照方法。

- **GraphSAGE**  
  基于邻居聚合的图神经网络模型，适合大规模、噪声较多的图结构。

- **Graph Attention Network（GAT）**  
  引入注意力机制，对邻居节点进行加权聚合。

- **GATv2**  
  对传统 GAT 注意力计算方式进行改进，提高模型表达能力。

---

## 实验设置

- **数据集**：Twitter15（多分类谣言检测数据集）
- **任务类型**：节点多分类（4 类：non-rumor / false / true / unverified）
- **评价指标**：
  - Accuracy
  - Macro-F1
  - AUC

实验过程中仅对具有真实标签的源节点进行评估，其余节点作为传播结构中的辅助节点。
